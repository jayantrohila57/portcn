Portcn `v0.6.0` is a Linux-first CLI for local service discovery. Runtime inspection is read-only; users can explicitly save local service details or open a selected local URL. It includes native listener and process/project evidence, an interactive dashboard, optional Docker inventory, local endpoint/readiness/connection checks, bounded port waiting, and a read-only stdio MCP server. The package also supports macOS `list`, `inspect`, and `diagnose` through `lsof`; Linux process/project details are unavailable there. Windows discovery and process/service management are not implemented. The [product roadmap](https://github.com/jayantrohila57/portcn/blob/dev/PRODUCT-ROADMAP.md) distinguishes verified releases from pending work.
