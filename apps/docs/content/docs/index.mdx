---
title: Project status
description: Current development status of portcn.
---

portcn is in early development. Its CLI foundation now provides branded help and version output, and the shared core validates numeric port ranges. Port discovery, process management, and service management are not implemented yet.

The repository includes this Fumadocs site and the CLI workspace foundation. The product is planned as a Linux-first developer tool, starting with Ubuntu.

The documentation will be expanded as working CLI capabilities are added.
