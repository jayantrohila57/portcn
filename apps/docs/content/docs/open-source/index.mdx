Portcn is an MIT-licensed open-source project. Read the canonical [license](https://github.com/jayantrohila57/portcn/blob/main/LICENSE) before reuse.

- Report reproducible defects with the [bug report form](https://github.com/jayantrohila57/portcn/issues/new?template=bug_report.yml).
- Propose behavior with the [feature request form](https://github.com/jayantrohila57/portcn/issues/new?template=feature_request.yml).
- Report security vulnerabilities using the private process in [SECURITY.md](https://github.com/jayantrohila57/portcn/blob/main/SECURITY.md).
- Read [CONTRIBUTING.md](https://github.com/jayantrohila57/portcn/blob/main/CONTRIBUTING.md) before opening a pull request.

Portcn is early development. The current CLI foundation does not yet discover or manage ports and services.
