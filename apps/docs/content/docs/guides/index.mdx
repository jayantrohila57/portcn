## Build and invoke from a checkout

Use the source workflow while Portcn remains unreleased:

```sh
pnpm install --frozen-lockfile
pnpm build
node apps/cli/dist/index.js --help
```

The CLI currently prints help and version information only. For its exact options, see [CLI Reference](/docs/cli-reference).

## Explore the documentation

The Fumadocs site supports searchable pages, a table of contents, Markdown copy/view options, and Markdown/LLM-friendly exports. Start at [Getting Started](/docs/getting-started).

<Callout title="Not available yet" type="warn">
Port scanning, process termination, service monitoring, and automatic Docker discovery are not implemented. Do not use the current CLI as if it performed those tasks.
</Callout>
