## Build and invoke from a checkout

Build from source to use the latest development commands:

```sh
pnpm install --frozen-lockfile
pnpm build
node apps/cli/dist/index.js --help
```

The published `v0.3.0` CLI includes `list`, `inspect`, and `diagnose`. For exact commands, output, and exit codes, see [CLI Reference](/docs/cli-reference). Additional capabilities remain planned until their implementation is released.

## Explore the documentation

The Fumadocs site supports searchable pages, a table of contents, Markdown copy/view options, and Markdown/LLM-friendly exports. Start at [Getting Started](/docs/getting-started).

<Callout title="Current boundary" type="warn">
Portcn reports sockets visible to `ss` in the current Linux network namespace. It does not scan unused ports, terminate processes, monitor services, or discover Docker namespaces automatically.
</Callout>
