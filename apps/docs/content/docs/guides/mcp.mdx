---
title: MCP server for coding agents
description: Connect coding agents to Portcn's read-only local listener and availability tools.
---

Portcn includes a local Model Context Protocol server for coding agents. It uses stdio, reads the current Linux network and process namespaces, and exposes only bounded read-only queries. It does not run a model, require an API key, open an HTTP server, or provide process-control tools.

## Start the server

The published `portcn` executable must be on `PATH`:

```json
{
  "mcpServers": {
    "portcn": {
      "command": "portcn",
      "args": ["mcp"]
    }
  }
}
```

For a source checkout, build the workspace and set the command to `node` with arguments `/absolute/path/to/portcn/apps/cli/dist/index.js` and `mcp`.

## Available tools

| Tool | Purpose | Bounds |
| --- | --- | --- |
| `list_listeners` | List visible TCP/UDP listeners with owner PID and process name when available. | Maximum 100 results; optional protocol filter. |
| `diagnose_port` | Report listener owners, namespace limits, and selected Git project evidence. | One port; up to 100 listeners and 20 owners per listener. |
| `check_port_availability` | Check observed overlap for one protocol and bind address. | One port and a local IP address. |
| `suggest_ports` | Return candidates with no observed overlap. | Maximum range 1024 ports and 20 suggestions. |

Tool schemas are advertised through MCP and invalid arguments are rejected before execution. Discovery uses the existing `ss` read path with a 10-second process timeout. Tool failures return structured MCP errors; stdio stdout is reserved for protocol messages.

## Read results carefully

<Callout title="A snapshot is not a reservation" type="warn">
An available result means Portcn observed no conflicting listener at that moment. It does not bind or reserve the port, and another process may claim it immediately.
</Callout>

Portcn only sees the current Linux network namespace. Process/project evidence may be incomplete because of permissions, process exits, or PID namespace boundaries. Project checkout details describe the current filesystem, not necessarily the code loaded by a running process. MCP diagnosis deliberately omits command lines, user identifiers, agent labels, session identifiers, and environment values.

The reusable [Portcn agent skill](https://github.com/jayantrohila57/portcn/tree/main/.agents/skills/portcn-agent) provides usage guidance for coding agents.
