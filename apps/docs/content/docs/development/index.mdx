## Install dependencies

```sh
corepack enable
pnpm install --frozen-lockfile
```

## Run the workspace

```sh
pnpm dev
```

This starts workspace development tasks configured by Turborepo. The Fumadocs app is available at `http://localhost:3000/docs`.

## Validate changes

For local CLI checks, use the Docker Compose commands in [Docker](/docs/docker). GitHub Actions runs lint, format, type, test, build, package, boundary, release, and docs checks directly on its runner with hooks disabled.

`pnpm docs:check` checks documentation links and CLI reference consistency; `pnpm build` compiles MDX as part of the Fumadocs production build. For docs-only development, install dependencies with the frozen lockfile and run `pnpm dev`.

<Callout title="Docs are part of the change" type="info">
Identify affected pages before coding. Update technical documentation in the same task and list those pages in the PR, or explain why no documentation change is required.
</Callout>
