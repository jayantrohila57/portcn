## Install dependencies

```sh
corepack enable
pnpm install --frozen-lockfile
```

## Runtime requirements

The source workspace and CLI build require Node.js 24 or later. The published `portcn@0.6.0` package requires Node.js 22 or later. CI installs the packed CLI artifact under Node 22 and checks installation, version/help output, MCP initialization, tool discovery, and structured tool errors. See the [Node.js release schedule](https://nodejs.org/en/about/previous-releases).

## Run the workspace

```sh
pnpm dev
```

This starts workspace development tasks configured by Turborepo. The Fumadocs app is available at `http://localhost:3000/docs`.

## Validate changes

Run workspace checks directly with pnpm:

```sh
pnpm lint
pnpm format:check
pnpm check-types
pnpm test
pnpm build
pnpm package:check
pnpm boundaries:check
pnpm release:check
pnpm docs:check
```

`pnpm docs:check` checks documentation links and CLI reference consistency; `pnpm build` compiles MDX as part of the Fumadocs production build. Before each commit, Git hooks run the full workspace checks and validate the commit message with pnpm. GitHub Actions runs its checks independently without Docker.

<Callout title="Docs are part of the change" type="info">
Identify affected pages before coding. Update technical documentation in the same task and list those pages in the PR, or explain why no documentation change is required.
</Callout>
