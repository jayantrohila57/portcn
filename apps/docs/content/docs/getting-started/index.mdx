This guide covers both the published CLI and a source checkout.

<Callout title="Current capabilities" type="info">
The published `v0.6.0` package requires Node.js 22 or later. Linux discovery requires `ss` from `iproute2`; Docker commands additionally require the user's Docker CLI and daemon permissions. The package includes limited macOS listener support for `list`, `inspect`, and `diagnose` through `lsof`. macOS does not provide Portcn's Linux process command lines, user IDs, project context, or agent markers. Windows discovery and process/service management are not implemented.
</Callout>

## Requirements

- Node.js 24 or later
- Node.js 22 or later to install the published CLI package
- pnpm 12.3.4 (the repository pins this version through Corepack)
- Git

Node.js 24 is required to build the source workspace. The published CLI package runs on Node.js 22 or later.

## Build and run Portcn

To install the published package:

```sh
npm install -g portcn
portcn --version
portcn --help
```

For a source checkout, build from the repository root:

<Tabs items={['Source checkout', 'Docker']}>
  <Tab value="Source checkout">

```sh
pnpm install --frozen-lockfile
pnpm build
node apps/cli/dist/index.js --help
```

  </Tab>
  <Tab value="Docker">

```sh
docker compose -f infra/docker/compose.yaml --profile cli run --build --rm cli --help
```

  </Tab>
</Tabs>

For a source checkout, use these steps:

<Steps>
  <Step>

### Clone and install

```sh
git clone https://github.com/jayantrohila57/portcn.git
cd portcn
corepack enable
pnpm install --frozen-lockfile
```

  </Step>
  <Step>

### Build the workspace

```sh
pnpm build
```

  </Step>
  <Step>

### Run the CLI

```sh
node apps/cli/dist/index.js --help
node apps/cli/dist/index.js --version
node apps/cli/dist/index.js list # Linux: iproute2; macOS: lsof
node apps/cli/dist/index.js diagnose 3000
```

  </Step>
</Steps>

## Run the documentation site

```sh
pnpm dev
```

Open `http://localhost:3000/docs`. For another port:

```sh
pnpm --filter @portcn/docs exec next dev --port 3001
```
