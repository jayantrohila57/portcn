# Security Policy

## Supported versions

The current public CLI release is maintained on `main`; security fixes are applied to the current `main` branch. The documentation app is maintained as part of the same repository. Package distribution is handled by the protected release workflows and is not a channel for reporting vulnerabilities.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's **Report a vulnerability** feature on the repository's Security tab when it is enabled. If private vulnerability reporting is unavailable, contact a repository owner through GitHub to arrange a private report. Include reproduction steps and impact; do not include credentials or unrelated personal data.
