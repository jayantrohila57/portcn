# Unified Linux service discovery

Portcn 0.7.0 adds a unified Linux dashboard for visible native and container services, including rootless Podman, local Nginx, and systemd service and socket units. It attributes rootlessport forwarding processes and deduplicates runtime observations by scoped identity.

Discovery reflects the current user's visibility and permissions. Container and service details may be partial when a runtime or system interface is unavailable. This release does not add unified dashboard support for macOS or Windows.

## Added

- integrate discovered services in unified dashboard (#187)
- discover visible service and socket units (#185)
- discover local Nginx services and listeners (#184)
- attribute rootlessport forwarding processes (#183)
- discover rootless containers and port mappings (#181)

## Fixed

- deduplicate runtime observations by scoped identity (#182)
