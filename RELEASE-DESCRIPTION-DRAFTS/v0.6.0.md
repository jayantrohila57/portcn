# More capable local service diagnostics

Portcn 0.6.0 adds a read-only MCP server for coding agents, bounded port waiting, support for running the packaged CLI on Node.js 22 or newer, and Linux socket tools in the packaged Docker image. Building the source workspace still requires Node.js 24.

The release adds macOS port and process discovery for `list`, `inspect`, and `diagnose`. The macOS adapter reports visible listener PIDs and process names; Linux-only command, user, project, and agent details remain unavailable. This release does not claim full macOS platform parity or Windows support.

## Added

- add bounded port wait (#139)
- add macOS port and process discovery (#140)
- support Node.js 22 runtime (#142)
- expose Portcn as a read-only MCP server for coding agents (#104)

## Fixed

- include Linux socket tools in CLI images
- report port wait timeouts accurately (#139)
