# Port conflict diagnosis

Portcn can now explain why a port is occupied by showing every visible TCP and UDP listener, its bind address and IP family, process owners, and the current network and PID namespace. It also explains when permissions or namespace boundaries limit the details it can see.

### Added

- diagnose port conflicts with owner and namespace details ([#95](https://github.com/jayantrohila57/portcn/issues/95))

Terminal demo: `portcn diagnose 3000 --json`
