# Local service intelligence

Portcn now combines versioned agent-facing diagnostics, port availability and project context with saved services, a structured terminal view, read-only Docker inventory, and bind-scope evidence. These are point-in-time observations; they do not establish external reachability or change processes or containers.

## Added

- report potential service exposure and bind scope ([#102](https://github.com/jayantrohila57/portcn/issues/102))
- discover containers and compose port mappings ([#101](https://github.com/jayantrohila57/portcn/issues/101))
- persist favorites aliases and custom service groups ([#100](https://github.com/jayantrohila57/portcn/issues/100))
- add service table and contextual details ([#97](https://github.com/jayantrohila57/portcn/issues/97))
- establish terminal design system ([#118](https://github.com/jayantrohila57/portcn/issues/118))
- verify endpoints against expected projects ([#108](https://github.com/jayantrohila57/portcn/issues/108))
- add read-only process ownership safety checks ([#111](https://github.com/jayantrohila57/portcn/issues/111))
- attribute agent-started services and detect leftover processes ([#103](https://github.com/jayantrohila57/portcn/issues/103))
- associate listening services with projects and worktrees ([#96](https://github.com/jayantrohila57/portcn/issues/96))
- check port availability and suggest alternatives ([#99](https://github.com/jayantrohila57/portcn/issues/99))
- add versioned JSON contracts ([#98](https://github.com/jayantrohila57/portcn/issues/98))
