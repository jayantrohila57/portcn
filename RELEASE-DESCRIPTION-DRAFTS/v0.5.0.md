# Local service readiness and diagnostics

Portcn now checks selected local services in stages, distinguishing a listening socket from TCP reachability and HTTP readiness. The diagnostics include resolution, IPv4/IPv6 connection evidence, bind scope, validated HTTP/TLS results, and Docker port mapping metadata when available. Every check is bounded and reports its network-namespace vantage point; it does not scan external hosts or change services.

## Added

- diagnose local service connection failures (#109)
- check service readiness with explicit local probes (#114)
- detect local HTTP HTTPS endpoints and open service URLs (#107)
