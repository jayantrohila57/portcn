# Portcn CLI foundation

The first packaged Portcn command provides branded help and version output.

## Added

- Install the `portcn` command and use `--version`, `--help`, or no arguments for the default branded output.

Port discovery and process or service management were not part of this release.

## Terminal demo

```sh
portcn --version
portcn --help
```
